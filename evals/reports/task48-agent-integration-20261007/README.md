Los registros `local-lab/`, `final-lab/`, `sdk/`, `verified-sdk/` y `verified-lab/` son comprobaciones anteriores conservadas por trazabilidad. El cierre actual usa `verified-e2b-live/` y `verified-sdk-real-host/`. `host.json` contiene un error de transporte CRLF y **no sirve como preflight**. Los errores reales de creación duplicada del usuario y CIDR IPv6 rechazado se corrigieron antes del recorrido aprobado. El SDK serializa `::/0`, pero el servidor lo rechaza: la versión final bloquea IPv4 en E2B y deshabilita/verifica IPv6 en la microVM, con una regresión que impide aceptar un puerto cerrado como prueba de bloqueo.

Las medidas E2B son una muestra de cada modalidad, con infraestructura encendida y plantilla construida. Excluyen instalación, descargas y construcción; no son percentiles ni promesas de producción. El receptor devuelve el marcador sintético antes/después desde otra red. El cálculo tiene UID 1000 y capacidades cero; `NoNewPrivs` de ese proceso E2B es 0, mientras ejecutor y QEMU lo fijan a 1. No se afirma una auditoría exhaustiva de aislamiento ni se habilitan usuarios reales.
